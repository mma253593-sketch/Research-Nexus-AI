# XAUUSD Smart Entry V2.0 — Adaptive Precision Engine (Quadcode Script / IQ Option)

Indicator แจ้งจังหวะเข้าเทรด **CALL / PUT / WAIT** สำหรับ XAUUSD (Digital Options, M1)
เขียนด้วย **Quadcode Script (QCS)** ซึ่งอิง Lua 5.3 ใช้ใน Script Editor ของ IQ Option

> เป็นเครื่องมือช่วยตัดสินใจ **ไม่ใช่บอทเทรดอัตโนมัติ** และ **ไม่รับประกันกำไร**
> ไม่มี Backtest บนแพลตฟอร์ม, ไม่ส่งคำสั่งซื้อขาย, ไม่เชื่อมต่อ API ภายนอก

## สิ่งที่เปลี่ยนจาก V1

- **ระบบจำแนกสภาพตลาด 5 แบบ** TREND / RANGE / HIGH VOL / LOW VOL / TRANSITIONAL พร้อมกันการสลับไปมาด้วย Hysteresis
- **เกณฑ์กรองปรับตามสภาพตลาด** ช่วงไม่ชัดเจนจะเข้มขึ้น ส่วนตลาดออกข้าง/ผันผวนสูงจะเป็น WAIT เสมอ
- **ตรวจสัญญาณ 5 ขั้น** และตัวจับสัญญาณหลอกเพิ่ม: โมเมนตัมอ่อน, Exhaustion, Whipsaw, Structure break
- **Score 2.0** ลดการนับซ้ำ มีการหักคะแนนเมื่อหลักฐานขัดกัน
- **สัญญาณน้อยลงมาก** (ประมาณ 4 ครั้งต่อ 1000 แท่งบนข้อมูลจำลอง เทียบกับ 18 ของ V1)
- รายละเอียดทั้งหมดอยู่ใน `docs/CHANGELOG.md`

## 1. ไฟล์ที่ใช้ติดตั้ง

| ไฟล์ | หน้าที่ |
|---|---|
| `scripts/XAUUSD_Smart_Entry_Main.lua` | ซ้อนบนกราฟ: EMA 9/21/50, แนวรับ/ต้าน (ย่อย+หลัก), ลูกศร, แท่งยืนยัน, ป้ายเปลี่ยนสภาพตลาด, เครื่องหมายยกเลิก |
| `scripts/XAUUSD_Smart_Entry_Panel.lua` | หน้าต่างล่าง: Score 2.0, คะแนนขั้นต่ำที่ต้องการ (ปรับตามตลาด), แรงซื้อ/ขาย, แถบสภาพตลาด, เหตุผลที่ยกเลิก |
| `scripts/XAUUSD_Smart_Entry_Lite.lua` | **รุ่นสั้นไฟล์เดียว (252 บรรทัด)** ใช้แทน Main + Panel ได้: สัญญาณเหมือน Main ทุกแท่ง (ทดสอบแล้ว) แสดงเฉพาะ EMA, แนวรับ/ต้าน, ลูกศร และ NO CHASE ตั้งค่าได้ 3 อย่าง (Min score, Cooldown, Trade transitional) |

## 2. วิธีติดตั้งใน IQ Option

1. เปิดกราฟ **XAUUSD** ตั้ง Timeframe **1 นาที**
2. **Indicators → Scripts → Add manually** (หรือ Import ไฟล์ `.lua`)
3. ลบโค้ดตัวอย่าง วางไฟล์ `XAUUSD_Smart_Entry_Main.lua` **ทั้งไฟล์** → **Save** → **Add to chart**
4. ทำซ้ำกับ `XAUUSD_Smart_Entry_Panel.lua`
5. ถ้าแก้ Settings ในสคริปต์หนึ่ง ต้องแก้ค่าเดียวกันในอีกสคริปต์ด้วย
6. หากเคยติดตั้ง V1 ให้ลบออกก่อน เพื่อไม่ให้ลูกศรซ้อนกัน

## 3. วิธีอ่านสัญญาณ

### บนกราฟราคา (Main)

| สิ่งที่เห็น | ความหมาย |
|---|---|
| ลูกศรเขียวขึ้น `CALL 85+` / `CALL 70+` | CALL บน**แท่งเข้าเทรด** |
| ลูกศรแดงลง `PUT 85+` / `PUT 70+` | PUT บน**แท่งเข้าเทรด** |
| จุดบนแท่งก่อนหน้า + `ENGULF` `FALSE-BRK` `REJECT` `PIN` `BREAKOUT` `MOMENTUM` | **แท่งยืนยัน** และรูปแบบที่ทำให้เกิดสัญญาณ |
| `NO CHASE` สีส้ม | ราคาวิ่งไปทางสัญญาณเกิน 0.35 ATR แล้ว → อย่าไล่ |
| ธงด้านบน `TREND` `RANGE` `HI-VOL` `LO-VOL` `TRANS` | สภาพตลาดเพิ่งเปลี่ยน (ยืนยันแล้ว) |
| `X:SR` `X:REGIME` `X:VOL` `X:LATE` (`X:MOM` เปิดใน Settings) | มี Setup ครบแต่**ถูกยกเลิก** → WAIT |
| เส้นแดง/เขียว | แนวต้าน/แนวรับย่อยล่าสุด |
| เส้นขาวจาง | แนวต้าน/แนวรับหลัก (Pivot 15 แท่ง) |

### หน้าต่าง Panel

| สิ่งที่เห็น | ความหมาย |
|---|---|
| แท่งคะแนน เขียว / แดง / เทา | CALL / PUT / WAIT |
| เส้น `CALL Score` / `PUT Score` | คะแนน 2.0 ของแต่ละฝั่ง |
| เส้นเหลือง `Required Score (adaptive)` | คะแนนขั้นต่ำที่ต้องการในสภาพตลาดตอนนี้ (70 ในเทรนด์, 78 ในช่วงเปลี่ยนผ่าน) |
| แถบสี่เหลี่ยมด้านล่าง | ฟ้า = Trend, เทา = Range, ส้ม = High Vol, น้ำเงิน = Low Vol, เหลือง = Transitional |
| ข้อความเล็กด้านบน | เหตุผลที่ยกเลิก: `SR` `RANGE` `TRANS` `LOVOL` `VOL` `LATE` `RSI` `CONF` `WEAK` `WHIP` `EXH` `REV` `PA` `CD` |
| Legend: `Status`, `Trend`, `Regime`, `ADX` | ค่าของแท่งล่าสุด (Regime: 1 Trend, 2 Range, 3 HiVol, 4 LoVol, 5 Trans) |

**คะแนนคือความสอดคล้องของเงื่อนไขทางเทคนิค ไม่ใช่โอกาสชนะ** คะแนน 90 ไม่ได้แปลว่าชนะ 90%

## 4. จังหวะเข้าเทรด

1. ทุกเงื่อนไขคำนวณจาก**แท่งที่ปิดแล้ว** ลูกศรขึ้นตอนเปิดแท่งใหม่และ**ไม่เปลี่ยนระหว่างแท่ง**
2. เข้าที่ต้นแท่งที่มีลูกศร (เช่น ภายใน 10–20 วินาทีแรกของ M1)
3. สัญญาณ**หมดอายุเมื่อแท่งนั้นปิด** ห้ามตามเข้าแท่งถัดไป
4. เห็น `NO CHASE` ให้ข้าม
5. Expiry ทดสอบได้ที่ 1–3 แท่ง (เครื่องมือประเมินผลรองรับ 1/2/3/5 แท่ง)

## 5. สภาพตลาดและการปรับเกณฑ์ (สรุป)

| สภาพตลาด | เทรดได้ไหม | การปรับ |
|---|---|---|
| TREND | ได้ | เกณฑ์มาตรฐาน: คะแนน ≥ 70, Cooldown 3 แท่ง |
| TRANSITIONAL | ได้ (ปิดได้) | เข้มขึ้น: คะแนน ≥ 78, ระยะถึงแนว ≥ 1.2 ATR, MACD ต้องเร่งตัว, ต้องมีรูปแบบแท่งเทียน, Cooldown 5 |
| RANGE | **WAIT** | — |
| HIGH VOL | **WAIT** (เข้าโหมดทันทีเมื่อมีแท่งกระชาก) | — |
| LOW VOL | WAIT (เปิดได้ใน Settings แล้วใช้เกณฑ์เข้ม) | — |

กฎทั้งหมดพร้อมตัวเลขและเหตุผลอยู่ใน `docs/ADAPTIVE_ENGINE_SPEC.md`

## 6. เงื่อนไข CALL โดยย่อ (PUT สมมาตร)

1. ตลาดอยู่ในสภาพที่เทรดได้
2. EMA21 > EMA50, ราคาปิด > EMA50, EMA50 ชันขึ้น, EMA9 > EMA21
3. ไม่หลุดโครงสร้าง: ปิดไม่ต่ำกว่า Swing low ล่าสุด
4. RSI > 50 (ช่วงเปลี่ยนผ่าน > 52) และ MACD Histogram > 0
5. Histogram ไม่อ่อนแรงลงต่อเนื่อง 2 แท่ง
6. EMA9/21 ไม่ตัดกันเกิน 1 ครั้งใน 10 แท่ง
7. ไม่ Overbought และไม่ Exhaustion (แท่งเขียวติดกันไม่ถึง 5 แท่ง, ไม่มีไส้บนยาวที่จุดสูงสุดใหม่)
8. มีรูปแบบแท่งเทียนผ่านเกณฑ์คุณภาพ และราคาปิดอยู่ครึ่งบนของแท่ง
9. ไม่สาย: Body ≤ 1.8 ATR และห่าง EMA21 ≤ 2.2 ATR
10. มีที่ว่างถึงแนวต้านถัดไป (ย่อย/หลัก/High 50 แท่ง/เลขกลม) ≥ 0.8 ATR
11. Score 2.0 ≥ เกณฑ์ และพ้นช่วง Cooldown

## 7. ข้อจำกัดของระบบ

1. **ยังไม่ได้ทดสอบกับข้อมูลราคาจริง** ผลการประเมินด้วยข้อมูลจริงยังไม่สมบูรณ์ (`docs/PERFORMANCE_REPORT.md`) จึง**ไม่มีหลักฐานว่า V2 ชนะบ่อยกว่า V1**
2. **ยังไม่ได้รันบน IQ Option จริง** ทดสอบด้วยตัวจำลองเท่านั้น ต้องลองบัญชี Demo ก่อน
3. ไม่เห็นข่าวเศรษฐกิจ ควรหลีกเลี่ยง NFP, CPI, FOMC เอง
4. สัญญาณช้ากว่าที่ตาเห็นประมาณ 1 แท่ง ซึ่งเป็นราคาของการกัน Repainting
5. สัญญาณน้อย (ประมาณ 4 ครั้งต่อ 1000 แท่งบนข้อมูลจำลอง) อาจมีหลายชั่วโมงที่ไม่มีสัญญาณ
6. ต้องมีประวัติอย่างน้อยประมาณ 115 แท่งก่อนเริ่มทำงาน
7. ข้อความบนกราฟเป็นข้อความคงที่ เพราะ QCS ไม่มีฟังก์ชันป้ายข้อความแบบไดนามิก คะแนนจริงดูที่ Panel/Legend
8. ค่าเริ่มต้นออกแบบสำหรับ XAUUSD M1 ถ้าใช้ Timeframe อื่นต้องทดสอบใหม่
9. ADX ไม่ใช่ฟังก์ชันสำเร็จรูปของ QCS ระบบคำนวณเองด้วยสูตรเดียวกับสคริปต์ ADX ทางการของ Quadcode
10. ไม่ทราบขีดจำกัดจำนวน plot ต่อสคริปต์ของ QCS: Main ใช้ 11 plot + 35 plot_shape (V1: 9 + 32)
