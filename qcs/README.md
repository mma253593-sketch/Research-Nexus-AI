# XAUUSD Smart Entry V3 — Precision Fast Entry (M1, Expiry 1 นาที)

Indicator แจ้งจังหวะ **CALL / PUT / WAIT** สำหรับ XAUUSD Digital Options บน IQ Option
เขียนด้วย Quadcode Script (QCS, อิง Lua 5.3) และต่อยอดจาก **V1** ตามที่ผู้ใช้เลือก (V2 เก็บไว้ที่ `archive/v2/`)

> เป็นเครื่องมือช่วยตัดสินใจ ไม่ใช่บอทเทรด ไม่รับประกันกำไร **ต้องทดสอบด้วยบัญชี Demo ก่อนใช้จริงเสมอ**

## สิ่งที่เปลี่ยนจาก V1

- **เข้าเทรดได้ 2 แบบ**
  - Momentum Entry: เข้าตามแรงส่งของแนวโน้ม
  - Pullback Entry: รอราคาย่อตัวเข้าโซน EMA9 แล้วเข้าตอนแนวโน้มกลับมา
- **แก้ปัญหา X:LATE ในขาลง** ตรวจแล้วว่าเกิดจากเงื่อนไข "ราคาห่าง EMA21 เกิน 2.2 ATR" ทั้งหมด ในขาลงแรงบนข้อมูลจำลอง V1 ให้ PUT 0 ครั้ง ส่วน V3 ให้ 14 ครั้ง (ทั้งหมดมาจาก Pullback Entry)
- **ตัวกรองเพิ่ม**
  - Sideways: ใช้ Efficiency Ratio และต้องยืนยัน 2 แท่งก่อนเปลี่ยนสถานะ
  - High Volatility: ค้างสถานะไว้จนกว่า ATR จะลดลง
  - Low Volatility, Exhaustion และ Reversal
- **สถานะใหม่**: READY, EXPIRED, BLOCKED พร้อมแสดงเหตุผลที่บล็อก
- **ทุกค่าปรับได้ใน Settings**

## ติดตั้ง

1. เปิดกราฟ XAUUSD ตั้ง Timeframe เป็น M1
2. ไปที่ Indicators → Scripts → Add manually
3. วางโค้ด Mini (หรือ Main) ทั้งไฟล์ → Save → Add to chart
4. ถ้าต้องการหน้าต่างคะแนน ให้ทำซ้ำกับไฟล์ Panel โดยใช้ Settings ให้เหมือนกัน
5. รอให้กราฟมีอย่างน้อย 115 แท่ง

## อ่านสัญญาณบนกราฟ

| สิ่งที่เห็น | ความหมาย |
|---|---|
| ลูกศรเขียว `CALL 85+` / `CALL 75+` / `CALL 70+` | CALL ระดับ Strong / Good / Moderate: เข้าที่ต้นแท่งนี้ Expiry 1 นาที |
| ลูกศรแดง `PUT 85+` / `PUT 75+` / `PUT 70+` | PUT (ความหมายเดียวกัน) |
| จุด + `MOMENTUM` หรือ `PULLBACK` บนแท่งก่อนหน้า | แท่งยืนยัน และประเภทของจังหวะเข้า |
| ◆ `READY` | กำลังย่อตัวในแนวโน้ม ให้เตรียมดู **ยังไม่ใช่สัญญาณเข้า** |
| `NO CHASE` | ราคาวิ่งจากราคาเปิดไปแล้ว อย่าไล่ราคา (เป็นคำเตือนสด ไม่เปลี่ยนสัญญาณ) |
| `X:LATE` | ราคาห่างจากจุดเข้าที่เหมาะสมแล้ว |
| `X:SR` | ที่ว่างถึงแนวรับ/ต้านไม่พอ |
| `X:SIDE` | ตลาดไม่มีทิศทาง |
| `X:VOL` | ความผันผวนผิดปกติ |

ใน Panel ค่า Status จะเป็นตัวเลข:
- `2` = CALL, `-2` = PUT
- `1` = CALL READY, `-1` = PUT READY
- `3` = EXPIRED (สัญญาณแท่งที่แล้ว หมดอายุแล้ว)
- `4` = BLOCKED (มีป้าย `BLOCK: ...` บอกเหตุผล)
- `0` = WAIT

**คะแนนไม่ใช่โอกาสชนะ**

## วิธีเข้าเทรด

1. ลูกศรขึ้นตอนเปิดแท่งใหม่ และไม่เปลี่ยนระหว่างแท่ง
2. เข้าภายในไม่กี่วินาทีแรกของแท่งที่มีลูกศร เลือก Expiry 1 นาที
3. ถ้าพลาดแท่งนั้น สัญญาณหมดอายุ (EXPIRED) ห้ามเข้าตาม
4. เห็น `NO CHASE` ให้ข้าม

รายละเอียดกฎทั้งหมดอยู่ใน `docs/FAST_ENTRY_CONFIG.md`

## ผลทดสอบและข้อจำกัด

- **ชุดทดสอบผ่าน 56/56 รายการ**
  - ไม่มี repainting จากการจำลอง tick 48,000 ครั้ง
  - Main/Panel ตรงกันทุกค่า
  - สัญญาณทุกตัวผ่านการตรวจกฎซ้ำแบบอิสระ
- **ยังไม่มีผลกับข้อมูลราคาจริง**: บนข้อมูลจำลอง V1/V2/V3 ให้อัตราชนะที่แยกกันไม่ออกทางสถิติ จึง**ไม่มีหลักฐานว่า V3 แม่นกว่า**
- **V3 ยิงสัญญาณบ่อยกว่า V2 มาก** (บนข้อมูลสุ่มประมาณ 26 ครั้งต่อ 1,000 แท่ง)
- **ยังไม่เคยรันบน IQ Option จริง** และระบบมองไม่เห็นข่าว

รายงานเต็มอยู่ที่ `docs/FAST_ENTRY_TEST_REPORT.md`
