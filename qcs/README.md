# XAUUSD Smart Entry Signal System (Quadcode Script / IQ Option)

ระบบ Indicator แจ้งจังหวะเข้าเทรด **CALL / PUT / WAIT** สำหรับ XAUUSD (Digital Options)
เขียนด้วย **Quadcode Script (QCS)** ซึ่งเป็นภาษาที่ IQ Option ใช้ (อิง Lua 5.3) — ไม่ใช่ Pine Script, ไม่ใช่ Python

> ระบบนี้เป็น **ตัวแจ้งสัญญาณเท่านั้น** ไม่มี Backtest, ไม่มีการจำลองกำไรขาดทุน, ไม่ส่งคำสั่งซื้อขาย และไม่เชื่อมต่อ API ภายนอก

---

## 1. ไฟล์ที่ใช้ติดตั้ง

| ไฟล์ | หน้าที่ |
|---|---|
| `scripts/XAUUSD_Smart_Entry_Main.lua` | ซ้อนบนกราฟราคา: EMA 9/21/50, แนวรับ/แนวต้าน, ลูกศร CALL/PUT, ชื่อแท่งยืนยัน, เครื่องหมายสัญญาณถูกยกเลิก |
| `scripts/XAUUSD_Smart_Entry_Panel.lua` | หน้าต่างแยกด้านล่าง: Confidence Score 0–100, แรงซื้อ/แรงขาย, สถานะปัจจุบัน, แถบแนวโน้ม, เหตุผลที่ยกเลิก |

ทั้งสองไฟล์ใช้ **เครื่องวิเคราะห์ชุดเดียวกัน** (`src/core.lua`) จึงให้ผลตรงกันเสมอ ถ้าตั้งค่า Input เหมือนกัน

## 2. วิธีติดตั้งใน IQ Option

1. เปิดกราฟ **XAUUSD** ในห้องเทรด (แนะนำ Timeframe 1 นาที หรือ 5 นาที)
2. กดปุ่ม **Indicators** → แท็บ **Scripts** (Script Editor)
3. เลือก **Add manually** (หรือ **Import** แล้วเลือกไฟล์ `.lua`)
4. ลบโค้ดตัวอย่างออกทั้งหมด แล้ววางเนื้อหาไฟล์ `XAUUSD_Smart_Entry_Main.lua` **ทั้งไฟล์**
5. กด **Save** → **Add to chart**
6. ทำซ้ำข้อ 3–5 กับไฟล์ `XAUUSD_Smart_Entry_Panel.lua`
7. ถ้าแก้ค่าใน Settings ของสคริปต์หนึ่ง ให้แก้ค่าเดียวกันในอีกสคริปต์ด้วย

## 3. วิธีอ่านสัญญาณ

### บนกราฟราคา (Main)

| สิ่งที่เห็น | ความหมาย |
|---|---|
| ลูกศร **เขียว ขึ้น** + `CALL 85+` / `CALL 70+` / `CALL 60+` | สัญญาณ CALL บน **แท่งเข้าเทรด** |
| ลูกศร **แดง ลง** + `PUT 85+` / `PUT 70+` / `PUT 60+` | สัญญาณ PUT บน **แท่งเข้าเทรด** |
| จุดเล็กบนแท่งก่อนหน้า + ข้อความ `ENGULF` `PIN` `REJECT` `BREAKOUT` `FALSE-BRK` `MOMENTUM` | **แท่งยืนยัน** และรูปแบบ Price Action ที่ทำให้เกิดสัญญาณ |
| `NO CHASE` สีส้ม | ราคาบนแท่งเข้าเทรดวิ่งไปแล้วเกินกำหนด → **ไม่ควรไล่ราคา** |
| `X:SR` `X:SIDE` `X:VOL` `X:LATE` (`X:RSI` `X:CONF` เปิดได้ใน Settings) | มี Setup ครบ แต่ **ถูกยกเลิก** ด้วยเงื่อนไขนั้น → WAIT |
| เส้นเหลือง / ฟ้า / ม่วง | EMA 9 / EMA 21 / EMA 50 |
| เส้นแดง / เขียว | แนวต้าน / แนวรับ ล่าสุด (Pivot ที่ยืนยันแล้ว) |
| ไม่มีลูกศร | **WAIT** |

### หน้าต่าง Panel

| สิ่งที่เห็น | ความหมาย |
|---|---|
| แท่งคะแนน **เขียว** / **แดง** / **เทา** | CALL / PUT / WAIT (สีเทาแสดงคะแนนดิบที่ดีที่สุด) |
| เส้น `CALL Score (raw)` / `PUT Score (raw)` | ความสอดคล้องของเงื่อนไขฝั่งซื้อ / ฝั่งขาย |
| เส้น `Buy Pressure %` / `Sell Pressure %` | แรงซื้อ/แรงขาย จากตำแหน่งราคาปิดในแท่ง (เฉลี่ย 5 แท่งที่ปิดแล้ว) |
| เส้นระดับ 85 / 70 / 60 | Strong / Good / Weak |
| ป้าย `CALL` / `PUT` ด้านบน | สัญญาณบนแท่งนั้น |
| สี่เหลี่ยมเล็กด้านล่าง เขียว / แดง / เทา | แนวโน้ม ขึ้น / ลง / ไม่มีแนวโน้ม (Sideways) |
| ข้อความเล็กด้านบน `SR` `SIDE` `VOL` `LATE` `RSI` `CONF` `PA` `CD` | เหตุผลที่สัญญาณถูกยกเลิก |
| ค่า `Status` และ `Trend` ใน Legend | `+1` CALL/ขึ้น, `-1` PUT/ลง, `0` WAIT/ไม่มีแนวโน้ม ของแท่งล่าสุด |

### ระดับคะแนน (Signal Confidence)

| คะแนน | ระดับ | การแสดงผล |
|---|---|---|
| 85–100 | Strong | `CALL 85+` / `PUT 85+` ลูกศรใหญ่สุด |
| 70–84 | Good | `CALL 70+` / `PUT 70+` |
| 60–69 | Weak | แสดงเฉพาะเมื่อปรับ `Min confidence` ลงเป็น 60–69 |
| ต่ำกว่าเกณฑ์ | WAIT | ไม่มีลูกศร |

**คะแนนคือความสอดคล้องของเงื่อนไขทางเทคนิค ไม่ใช่เปอร์เซ็นต์โอกาสชนะ**
ค่าเริ่มต้น `Min confidence = 70` (เน้นคุณภาพ) และระบบไม่มีทางแสดง CALL/PUT ที่คะแนนต่ำกว่าเกณฑ์นี้

## 4. จังหวะเข้าเทรด (Entry Timing)

1. **แท่งยืนยัน** = แท่งที่ **ปิดแล้ว** ล่าสุด ทุกเงื่อนไขคำนวณจากแท่งนี้เท่านั้น
2. **แท่งเข้าเทรด** = แท่งใหม่ที่เพิ่งเปิด ลูกศรจะปรากฏตั้งแต่เปิดแท่ง และ **ไม่เปลี่ยน/ไม่หายไป** ระหว่างแท่งวิ่ง
3. **เข้าเทรดที่ต้นแท่งใหม่** ควรเข้าภายในช่วงแรกของแท่ง (เช่น 10–20 วินาทีแรกบน M1)
4. **สัญญาณหมดอายุเมื่อแท่งเข้าเทรดปิด** ถ้าพลาดแท่งนั้น ห้ามเข้าตามในแท่งถัดไป ให้รอสัญญาณใหม่
5. **ห้ามไล่ราคา** ถ้าเห็น `NO CHASE` (ราคาวิ่งไปทางสัญญาณเกิน 0.35 × ATR จากราคาเปิดแล้ว) ให้ข้าม
6. **Expiry แนะนำ** 1–3 แท่งของ Timeframe ที่ใช้ (เช่น M1 → 1–3 นาที) ผู้ใช้ควรทดสอบเองว่าแบบไหนเหมาะ

### กรณีที่ไม่ควรเข้า แม้ทิศทางจะถูก

- มีเครื่องหมาย `X:...` หรือ Panel เป็นสีเทา
- `NO CHASE` ปรากฏ
- กำลังจะมีข่าวสำคัญของทองคำหรือดอลลาร์ (NFP, CPI, FOMC) ระบบมองไม่เห็นข่าว
- สเปรดหรือ Payout ของ IQ Option ผิดปกติ
- เพิ่งมีสัญญาณไปไม่เกิน 3 แท่ง (ระบบบล็อกให้แล้วด้วย Cooldown)

## 5. เงื่อนไขการเข้าเทรด (ฝั่ง PUT สมมาตรกับ CALL ทุกข้อ)

### เงื่อนไขบังคับของ CALL (ต้องผ่านทุกข้อ ไม่อย่างนั้นเป็น WAIT)

| # | เงื่อนไข (ดูจากแท่งที่ปิดแล้ว) | ถ้าไม่ผ่าน |
|---|---|---|
| 1 | ความผันผวนไม่ผิดปกติ: ช่วงแท่ง ≤ 2.8 × ATR และ ATR ≤ 1.9 × ATR เฉลี่ย 100 แท่ง | `VOL` |
| 2 | ไม่ Sideways: EMA 21 ไม่แบน **และ** BB ไม่บีบตัว / EMA ไม่พันกัน | `SIDE` |
| 3 | แนวโน้มหลักขึ้น: EMA21 > EMA50, Close > EMA50, EMA50 กำลังชันขึ้น และ EMA9 > EMA21 | (ไม่มีแนวโน้ม) |
| 4 | โมเมนตัมยืนยัน: RSI > 50 **และ** MACD Histogram > 0 | `CONF` |
| 5 | ไม่ Overbought เกินไป: RSI ≤ 78 | `RSI` |
| 6 | มี Price Action ฝั่งขึ้น และราคาปิดอยู่ครึ่งบนของแท่ง | `PA` |
| 7 | ไม่สาย: Body ≤ 1.8 × ATR และห่าง EMA21 ไม่เกิน 2.2 × ATR | `LATE` |
| 8 | มีที่ว่างถึงแนวต้านถัดไป ≥ 0.8 × ATR | `SR` |
| 9 | คะแนน ≥ Min confidence (70) | (ไม่แสดงเครื่องหมาย) |
| 10 | ไม่มีสัญญาณใน 3 แท่งก่อนหน้า | `CD` |

### การคิดคะแนน (รวม 100)

| หมวด | คะแนนเต็ม | รายละเอียด |
|---|---|---|
| Trend | 25 | EMA เรียงตัว 9>21>50 (12), Close > EMA21 (4), EMA50 ชันขึ้น (5), EMA9–EMA50 ห่าง ≥ 0.5 ATR (4) |
| RSI | 15 | 52–70 และกำลังขึ้น (15), 50–74 (10), 45–50 กำลังขึ้น (4) |
| MACD | 15 | Histogram > 0 (6), Histogram เพิ่มขึ้น (5), MACD > 0 (4) |
| Price Action | 20 | Engulfing (20), False Breakout (18), Pin Bar (16), Rejection (15), Breakout (14), Momentum candle (8) |
| ระยะถึงแนวต้าน | 15 | ≥ 2 ATR (15), ≥ 1.5 (12), ≥ 1.0 (8), ≥ 0.8 (4) |
| ความผันผวน | 10 | ATR ปกติและไม่บีบตัว (10), ไม่ผิดปกติ (5) |

### นิยาม Price Action (ฝั่งขึ้น)

- **Bullish Engulfing**: แท่งเขียวกลืนตัวแท่งแดงก่อนหน้าทั้งหมด และ Body ≥ 0.3 ATR
- **Pin Bar**: ไส้ล่าง ≥ 2 × Body และ ≥ 60% ของแท่ง, ไส้บน ≤ 25%, ช่วงแท่ง ≥ 0.5 ATR
- **Rejection**: แท่งเขียวที่มีไส้ล่าง ≥ 40% ซึ่งแตะ EMA21 หรือแนวรับ แล้วปิดเหนือ EMA21
- **Breakout**: ปิดเหนือแนวต้าน Pivot ล่าสุด + 0.1 ATR, แท่งก่อนยังปิดใต้แนว, Body ≥ 50% ของแท่ง
- **False Breakout**: หลุดแนวรับ Pivot ล่าสุดแล้วปิดกลับขึ้นมาเหนือแนว พร้อมไส้ล่างยาว
- **Momentum**: แท่งเขียว Body ≥ 50% และปิดใน 30% บนของแท่ง

### แนวรับ / แนวต้าน

- **Pivot**: จุดสูง/ต่ำที่สุดในหน้าต่าง ±5 แท่ง ยืนยันหลังจากแท่งด้านขวาปิดครบ 5 แท่ง (ไม่ใช้ข้อมูลอนาคต)
- ใช้ Pivot ล่าสุด 2 จุด + High/Low ของ 50 แท่งก่อนหน้า เป็นแนวที่ต้องตรวจระยะห่าง

## 6. การป้องกัน Repainting และสัญญาณซ้ำ

- ทุกการตัดสินใจใช้ข้อมูลแท่ง `[1]` (ปิดแล้ว) ลูกศรบนแท่งปัจจุบันจึงไม่เปลี่ยนแม้ราคาวิ่ง
- Pivot ยืนยันย้อนหลัง จึงไม่ย้ายตำแหน่ง
- มี Cooldown 3 แท่งหลังสัญญาณ (ปรับได้)
- เครื่องหมายยกเลิกแสดงเฉพาะแท่งแรกของแต่ละช่วงเหตุผล
- ข้อยกเว้นเดียวคือ `NO CHASE` ซึ่งอ่านราคาสดโดยตั้งใจ เป็นคำเตือนสด **ไม่ใช่สัญญาณ** และอาจปรากฏหรือหายไประหว่างแท่ง

## 7. การตั้งค่าที่ปรับได้ (Settings)

|---|---|
| Trend (EMA) | 9 / 21 / 50 |
| Momentum | RSI 14, บล็อก CALL > 78, บล็อก PUT < 22, MACD 12/26/9 |
| Volatility | BB 20 × 2.0, ATR 14, ATR baseline 100, Squeeze 0.75, Flat 0.25, Spike 2.8, Hot 1.9 |
| Support / Resistance | Pivot 5, Range 50, ระยะขั้นต่ำ 0.8 ATR |

| Display | เปิด/ปิด EMA, S/R, Range, BB, ชื่อแท่งยืนยัน, เครื่องหมายยกเลิก และกำหนดสี |

## 8. ข้อจำกัดของระบบ

1. **ไม่การันตีผลกำไร** คะแนนเป็นความสอดคล้องของเงื่อนไข ไม่ใช่โอกาสชนะ
2. **มองไม่เห็นข่าวและปัจจัยพื้นฐาน** ทองคำผันผวนแรงช่วงข่าว ระบบจับได้เฉพาะหลังแท่งปิดผ่านตัวกรองความผันผวน
3. **สัญญาณเกิดได้เฉพาะเมื่อแท่งปิด** จึงช้ากว่าการดูด้วยตาประมาณ 1 แท่ง ซึ่งเป็นราคาที่ต้องจ่ายเพื่อกัน Repainting
4. **ต้องการประวัติประมาณ 115 แท่ง** ก่อนเริ่มแสดงสัญญาณ (ช่วง Warm-up)
5. **แนวรับ/แนวต้านคำนวณจากราคาในกราฟเท่านั้น** ไม่รวมระดับจิตวิทยาหรือแนวจาก Timeframe ใหญ่
6. **ข้อความบนกราฟเป็นข้อความคงที่ต่อรูปแบบ** QCS ไม่มีฟังก์ชันตาราง/ป้ายข้อความแบบไดนามิก คะแนนจริงจึงอ่านจาก Panel และ Legend
7. **สคริปต์ Main และ Panel แยกกัน** ต้องตั้ง Input ให้ตรงกันเอง
8. **ค่าเริ่มต้นออกแบบสำหรับ XAUUSD M1–M5** ถ้าใช้ Timeframe อื่นควรทดสอบและปรับค่า
9. **มือถือบางรุ่นแทนรูปทรงบางแบบด้วยสี่เหลี่ยม/สามเหลี่ยม** ตามข้อจำกัดของแพลตฟอร์ม
10. **ยังไม่ได้ทดสอบบน IQ Option จริง** ผู้ใช้ต้องทดสอบด้วยบัญชี Demo ก่อนใช้งานจริงเสมอ

## 9. การตรวจสอบที่ทำแล้ว

- ใช้เฉพาะฟังก์ชันที่มีในเอกสารทางการ [quadcodescript-docs](https://quadcode-tech.github.io/quadcodescript-docs) และในสคริปต์ Built-in ทางการ [quadcodescript-library](https://github.com/quadcode-tech/quadcodescript-library):
  `instrument`, `input`, `input_group`, `ema`, `sma`, `rma`, `rsi`, `stdev`, `highest`, `lowest`, `max`, `tr`,
  `value_when`, `make_series`, `get_value`, `plot`, `plot_shape`, `rect`, `hline`, `rgba`
- ทำตามกฎของเอกสารว่า "เปรียบเทียบ series กับตัวเลขตรง ๆ ไม่ได้" ทุกการตัดสินใจจึงอ่านค่าผ่าน `get_value` แล้วใช้ `if` ของ Lua
- `luac5.3 -p` ตรวจ Syntax ผ่านทั้งสองไฟล์
- `test/run_tests.lua` รันสคริปต์จริงบน Mock runtime ที่จำลองการทำงานทีละแท่งของ QCS กับข้อมูลสังเคราะห์ 3 ชุด × 4000 แท่ง ตรวจว่า
  ไม่มี Repainting (จำลอง Tick ระหว่างแท่ง), ไม่มีสัญญาณใน Cooldown, ไม่มีสัญญาณที่คะแนนต่ำกว่าเกณฑ์ และ Main/Panel ให้ผลตรงกัน
  (Mock ไม่ใช่ Engine จริงของ IQ Option จึงไม่ได้พิสูจน์ว่าสคริปต์จะรันบนแพลตฟอร์มได้)

