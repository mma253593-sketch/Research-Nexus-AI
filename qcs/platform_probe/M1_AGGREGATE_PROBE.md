# M1 Aggregate Probe (TASK 03C)

`m1_aggregate_probe.lua` สร้างแท่ง M5 / M15 จากแท่ง M1 ของกราฟเอง แล้วให้ Owner เทียบกับแท่ง M5 / M15 จริงของ IQ Option
ใช้แทน `security()` ซึ่งทดสอบแล้วว่าไม่ส่งราคา M5/M15 ให้สคริปต์ (ดู `SECURITY_READ_DIAG.md`)
**ไม่ใช่ Indicator สำหรับเทรด และไม่ใช่ V2**

## วิธีทำงาน

| ขั้น | รายละเอียด |
|---|---|
| ข้อมูล | `open, high, low, close, open_time` ของกราฟ ผ่าน `get_value` (ยืนยันแล้วว่าเป็นตัวเลขบน IQ Option) |
| P | ระยะห่าง `open_time` ที่เล็กที่สุดที่เคยเห็น = 1 แท่งของกราฟ (ใช้ได้ทั้งหน่วยวินาทีและมิลลิวินาที) |
| กลุ่ม | `bucket = floor(open_time / (k × P))` โดย k = 5 หรือ 15 |
| แท่ง HTF | แท่งแรกของ bucket ตั้ง O/H/L/C ใหม่ แท่งถัดไปอัปเดต H/L/C |
| แท่งที่ปิดแล้ว | เมื่อขึ้น bucket ใหม่ ค่าของ bucket ก่อนหน้าจะถูกคัดลอกเป็น "last closed" และไม่เปลี่ยนอีก เพราะสร้างจากแท่ง M1 ที่ปิดแล้ว (`[1]`) เท่านั้น |

แท่ง HTF แรกบนกราฟมักนับได้ไม่ครบ (แท่งแรกสุดยังไม่รู้ค่า P) และจะขึ้น `5GAP` / `15GAP` ซึ่งเป็นเรื่องปกติ

## ตั้งค่าบน IQ Option

1. บัญชี Demo กราฟ **1m** (ทองคำ DIGITAL หรือ XAUUSD OTC ก็ได้ แต่ให้จดว่าใช้อันไหน)
2. เพิ่ม `m1_aggregate_probe.lua` (วางโค้ดทั้งไฟล์)
3. `View`: 1 = เส้น + ป้าย, 2 = ข้อความ M5, 3 = ข้อความ M15; `Bars per character` เหมือนสคริปต์ก่อนหน้า

## สิ่งที่แสดง

**View 1**: เส้น `M1 close`, `M5 forming close`, `M5 last CLOSED close`, `M15 forming close`, `M15 last CLOSED close` และป้ายบนแท่ง M1 แรกของแต่ละแท่ง HTF ใหม่
- `5OK` / `15OK`: แท่งที่เพิ่งปิดมี M1 ครบ 5 / 15 แท่ง
- `5GAP` / `15GAP`: จำนวนไม่ครบ (แท่งหาย ตลาดปิด หรือแท่งแรกของกราฟ)

**View 2 / 3**: ข้อความของแท่ง M5 / M15 ที่ปิดล่าสุด เช่น `M5 P=60 T=08:35 O=... H=... L=... C=... N=5 PH=0`
- `P`: ระยะของ 1 แท่ง (60 = หน่วยวินาที)
- `T`: เวลาเปิดของแท่งนั้น (จาก `date()` ใน timezone ของเครื่อง)
- `N`: จำนวนแท่ง M1 ในแท่งนั้น
- `PH`: ลำดับของแท่ง M1 ปัจจุบันภายในแท่ง HTF (0 = แท่งแรก)

## ขั้นตอนทดสอบ

1. **ตรงกับกราฟจริงหรือไม่**: Probe ต้องอยู่บนกราฟ **1m** เสมอ (ถ้าเปลี่ยนกราฟของแท็บนั้นเป็น 5m สคริปต์จะคำนวณใหม่จากแท่ง 5m และขึ้นป้าย `NOT 1M CHART`) ให้เปิด**อีกแท็บหนึ่ง**ของสินทรัพย์เดียวกันตั้งเป็น 5m ไว้เทียบ
   - View 2 บนแท็บ 1m: ข้อความเริ่มตรงไหน ค่าในข้อความคือแท่ง M5 ที่ปิดล่าสุด **ณ แท่งที่ข้อความเริ่ม** (ไม่ใช่แท่งล่าสุดของกราฟ) จด `T`, `O`, `H`, `L`, `C`
   - ในแท็บ 5m หาแท่งที่เปิดเวลา `T` แล้วเอาเมาส์ชี้ อ่าน O/H/L/C เทียบกัน ทำ 3 แท่ง
   - ทำแบบเดียวกันกับ View 3 และแท็บ 15m
2. **เวลาตรงกรอบหรือไม่**: `T` ของ M5 ต้องลงท้าย :00 :05 :10 … และของ M15 ต้องเป็น :00 :15 :30 :45 ส่วนป้าย `5OK` ต้องอยู่บนแท่ง M1 ที่เวลา :00 :05 :10 …
3. **ความเสถียร (Live)**: View 1 ดูเส้น `M5 last CLOSED close` อย่างน้อย 10 นาที เส้นนี้ต้องเปลี่ยนเฉพาะตอนขึ้นแท่ง M5 ใหม่เท่านั้น ระหว่างนั้นต้องนิ่ง
4. **Repaint ย้อนหลัง**: ถ่ายภาพไว้ แล้ว reload หน้า IQ Option และเทียบค่า `last CLOSED` ของแท่งเดิม ต้องเท่าเดิม
